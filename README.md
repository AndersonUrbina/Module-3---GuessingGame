# Module 2 - Number-Guessing-Game

## Description
This program generates a random number within a difficulty-based range and counts how many attempts it takes the user to guess the number.

## Getting Started
1. Download the repository files.
2. Open the project file with IntelliJ IDE or another Java editor.
3. Run the GuessingGame.java file.
